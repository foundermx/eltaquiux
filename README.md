# El Taquiux · menú digital

Menú para los clientes (se abre al escanear el QR de la mesa) y, más adelante, panel de administración.
Next.js 16 (App Router) + Tailwind CSS 4.

## Desarrollo

```bash
pnpm install
pnpm dev   # http://localhost:3000
```

Colores, fuentes, radios y sombras de la marca: `@theme` en `app/globals.css`.
